# 杭电图书馆自动预约

一个带图形界面的图书馆座位自动预约小工具。输入学号、密码，选择日期和时段，程序会在放号时刻自动提交预约。

> 仅供个人学习与自动化技术交流使用。请遵守学校图书馆的预约规则，预约成功后按时签到，避免违约。

## 功能

- 图形界面，无需命令行
- 学号密码登录（校园统一身份认证）
- 选择明天 / 后天，自由设置起止时间
- 按楼层整层预约，或填写自定义座位号（就是座位图上印的 3 位座位号，如 `001, 005-010`）
- 自定义座位分「首选 / 次选 / 备用」三档，逐档尝试
- 像闹钟一样定时：每周选中的星期几到点自动开始抢座，每个星期的使用时段可以单独设置
- 放号时刻自动等待（默认 20:00），提前登录并预热连接
- 服务器校时，避免早提交被判定为「超出可预约时间范围」
- 自动节流，规避接口限流
- 所选座位被占时，自动尝试同楼层其它座位
- 实时日志，随时可停止
- 联网检查新版本，可从 GitHub Releases 一键下载并自动替换更新

## 直接使用（推荐）

1. 安装 [Google Chrome](https://www.google.com/chrome/)（程序用 Chrome 完成登录）
2. 下载 `HDU_Lib_AutoBook.exe`
3. 双击运行，填写学号、密码，选择日期、时段与座位
4. 点击「开始预约」，等待日志输出结果

首次运行若弹出 Windows 安全提示，选择「仍要运行」即可。

## 从源码运行

```bat
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
python app.py
```

要求 Python 3.9 及以上。

## 打包 exe

```bat
build.bat
```

生成的文件在 `dist\HDU_Lib_AutoBook.exe`，可单文件分发。

## 使用说明

| 设置 | 说明 |
| --- | --- |
| 目标日期 | 图书馆一般晚上 20:00 放出后天的号源，选「后天」最常见 |
| 时段 | 24 小时制，结束时间需晚于开始时间，时长会自动换算 |
| 楼层整层 | 从该楼层第一个座位开始依次尝试 |
| 自定义座位 | 分首选 / 次选 / 备用三档，填写座位图上的 3 位座位号，按档次与填写顺序依次尝试；支持逗号、空格分隔和 `a-b` 区间。每个楼层的可选范围会在界面提示（如 `001-220`） |
| 扩展同层 | 候选座位用完后，按距离尝试同楼层其它座位 |
| 定时抢座 | 勾选「启用定时」，填写抢座时刻（如 `19:55:00`），并为每周勾选的星期单独设置开始/结束时间，到点自动开始抢座；程序需要保持运行 |
| 放号时刻 | 默认 `20:00:00`，到点才提交；取消勾选则立即提交 |
| 提交余量 | 比放号时刻晚多少毫秒提交，默认 120ms，用来避免提前 |
| 请求间隔 | 两次请求之间的间隔，默认 3300ms（实测安全值，改小可能被限流） |
| 最大尝试次数 | 单个时段的请求次数上限 |
| 放弃时间 | 超过该秒数仍未成功则停止 |
| 无头模式 | 不显示 Chrome 窗口，后台完成登录 |
| 检查更新 | 手动检查新版本；程序启动时也会静默检查一次。发现新版本后可一键下载，exe 会退出、替换并自动重启完成升级 |

## 座位优先级

自定义座位有三个输入框：

| 档位 | 说明 |
| --- | --- |
| 首选 | 最想要的座位，优先尝试 |
| 次选 | 首选抢不到时依次尝试，可留空 |
| 备用 | 兜底座位，可留空 |

三档都按填写顺序尝试，跨档位去重。若勾选「扩展同层」，三档用尽后还会按距离尝试同楼层其它座位。

## 定时抢座（像闹钟）

1. 勾选「启用定时」
2. 填写抢座时刻，如 `19:55:00`
3. 在「每周时段」勾选需要执行的星期，并给每个勾选的星期单独填写开始/结束时间（每天可以不一样）
4. 点击「开始预约」后程序会保持运行，到点自动登录并抢座；抢完一轮后继续等待下一个设定时点

界面会显示「下次自动抢座」的日期、时刻和该天使用的时段。例如勾选周一 10:00–22:00、周三 14:00–22:00，则周一 19:55 抢座时按 10:00–22:00 预约，周三 19:55 抢座时按 14:00–22:00 预约。未勾选的星期不会执行；勾选但未单独改动的星期沿用上方「预约计划」里的时段。放号时刻仍在高级设置里单独配置。若到点时已经有了预约，程序会提示「已有预约」并跳过。

## 座位号说明

图书馆有两套编号：

- **3 位座位号**：座位图和你预约记录里看到的号码，如 `001`、`061`，程序界面填的是这一套；
- **5 位座位 ID**：系统内部编号，下单时接口要求的就是它，如 `62565`。

程序按「同一房间内 5 位 ID 升序排列，第 1 个即 001」自动换算，你只需对照座位图填 3 位号。换算依赖所选楼层，所以自定义座位时也必须选对楼层。

## 常见问题

**登录失败 / 一直停在登录页**
确认学号密码正确，并能在浏览器中正常登录学校统一身份认证。关闭无头模式可以看到 Chrome 的实际操作过程。

**提示「超出可预约座位时间范围」**
说明提交得比放号时刻略早。保持「提交余量」不小于 100ms，并确认电脑时间准确。

**提示「您已有预约」**
同一时段只能有一条预约。先去图书馆系统取消已有预约，再重新运行。

**提示「操作过于频繁」**
触发限流。保持默认 3300ms 间隔，等待一段时间后重试。

**杀毒软件拦截**
打包后的 exe 未做数字签名，可能被误报。可自行从源码构建。

## 隐私说明

- 所有信息只保存在本机 `%APPDATA%\HDUAutoBook\settings.json`
- 密码仅在勾选「记住密码」时明文保存于本机，不勾选则不会写入
- 程序不会向任何第三方服务器上传数据，只与图书馆预约系统通信
- 「检查更新」只访问 GitHub 的版本发布接口获取版本号与下载地址，不携带学号、密码或任何个人信息
